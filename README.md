# Interactive Math Quiz & Equation Solver

A text-based Python program that generates math quizzes and solves equations based on the user's school level.

Features
* **Elementary School Mode:** Generates custom interactive quizzes on base-2 exponentiation or logarithms with automated grading.
* **High School Mode:** An interactive quadratic and linear equation calculator that supports real, repeating, and complex numbers.
* **Input Validation:** Dynamically sanitizes inputs to handle formatting changes gracefully.
